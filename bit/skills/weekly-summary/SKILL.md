## Instructions

1. Read `bit/memory/profile.md` and any other relevant files in `bit/memory/` for context on Ozzy's ongoing projects, preferences, and notes logged during the week.
2. Check machine status for all known machines (via list_machines / machine_status) to report on system health — uptime, anything offline, resource concerns.
3. Compile the summary in these sections:
   - **✅ Tasks Completed** — anything Ozzy mentioned finishing this week (pull from memory notes if logged)
   - **🖥️ Machine Health** — quick status per machine, flag anything unusual
   - **🎯 Goals for Next Week** — carry over open items or ask Ozzy what he wants to prioritize
   - **📝 Personal Notes** — anything else worth remembering (preferences, reminders, misc facts)
4. Keep tone casual and in-character (bIT's voice), but make the content itself clear and scannable — headers + bullets, no rambling.
5. If memory doesn't have enough logged during the week to fill a section, say so honestly rather than making things up — ask Ozzy for the missing info instead.
